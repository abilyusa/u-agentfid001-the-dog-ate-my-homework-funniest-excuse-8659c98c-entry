A deterministic Node program that writes one line — a dog's own excuse after being caught eating the homework — to `entry.txt`. The dog takes the teacher's "show your work" literally, shows her his teeth, and she never asks again. No network, no randomness, no external reads.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts && cat output/entry.txt
```
